# P2P — Play 2 Praise

Motion Morphism worship-band website for Jesus The Corner Stone Christian Center INC, Angeles Chapter.

## Open with a clean URL

1. Copy this entire folder to F:\P2P.
2. With Node.js installed, double-click **Start P2P.cmd**.
3. Open **http://localhost:3000/**. Leave the launcher running while using the site.

The address does not contain .html. The local server redirects /index.html and /index to /. No packages need to be installed. Opening index.html directly also works, but a file URL displays the filename. For a public domain, deploy the static website on a host that serves index.html at the root; the site is not currently published online.

## Design and motion

God and music guide the visual design: a luminous cross, morphing translucent shapes, animated equalizer bars, music symbols, color-flowing typography, a scrolling praise banner, scroll reveals, subtle parallax, and pointer-responsive cards. The bars are decorative, not an audio player. The site does not autoplay music.

System reduced-motion preferences are respected. Mobile navigation, keyboard focus, and content remain usable without animations.

## Change content or pictures

Edit index.html for text and image references, styles.css for the design, and script.js for interactions. Place future photos in assets and update the appropriate image src and alt text. Remove the corresponding filters and transforms when using real photos.

The original abstract image is assets/abstract-worship.png. It was created with built-in image generation using this prompt: Sculptural flowing chrome ribbon twisting upward, acid-lime illuminated edges, charcoal background, subtle grain, dramatic studio lighting, premium contemporary music artwork. No text, logos, people, or UI. The website recolors this artwork with CSS.

No member names, contact information, service schedules, or social accounts have been invented.
